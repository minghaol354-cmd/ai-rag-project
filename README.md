# 每日问答小工具

## 项目简介

这是一个基于知识库的每日问答小工具，支持随机导入知识库文档，生成题目，用户答题后进行判分和解析。

## 核心功能

1. **知识库管理**
   - 支持导入md、txt格式文档
   - 可多选文档批量导入
   - 知识库内容管理

2. **题目生成**
   - 生成随机问答题/判断题/选择题
   - 基于知识库内容生成
   - 引入教育性质出题强的大模型

3. **答题功能**
   - 一问一答的对话形式
   - 用户输入答案
   - 后台判官模块分析并打分

4. **结果展示**
   - 生成题号-答案判分与解析
   - 临时答案解析缓存
   - 可手动展开详细解析

5. **智能推荐**
   - 符合人类记忆逻辑与思维惯性的机制
   - 基于费曼学习法的题目推荐

6. **性能优化**
   - 后台缓存机制
   - 知识库检索优化
   - 长文本解读总结

## 技术栈

### 前端
- **HTML5** + **CSS3** + **JavaScript**
- **Bootstrap**：用于快速构建响应式界面
- **jQuery**：简化DOM操作和AJAX请求

### 后端
- **Python 3.8+**
- **Flask**：轻量级Web框架
- **SQLite**：本地数据库，适合小工具
- **Markdown**：解析md文档

### 大模型API
- **Hugging Face Inference API**：免费的开源大模型
- **llama.cpp**：本地运行开源大模型
- **GPT4All**：本地运行的大模型

### 工具库
- **NLTK**：自然语言处理
- **Scikit-learn**：机器学习（用于题目推荐）
- **PyPDF2**：PDF文档处理（可选）

## 安装与运行

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行应用

```bash
python app.py
```

然后在浏览器中访问 `http://localhost:5000`

## 使用说明

1. **导入知识库**：在上传页面选择md、txt格式的文档进行导入
2. **生成题目**：系统会基于知识库生成随机题目
3. **答题**：在答题界面输入答案并提交
4. **查看结果**：系统会判分并生成解析
5. **继续答题**：系统会根据费曼学习法推荐下一题

## 核心算法

### 题目推荐算法
- 基于费曼学习法的记忆曲线
- 优先推荐用户答错的题目
- 按照知识难度和重要性排序

### 答案判分算法
- 使用大模型进行语义理解
- 考虑答案的正确性、完整性和逻辑性
- 生成详细的解析和评分理由

### 知识库检索算法
- 基于TF-IDF的文本检索
- 语义相似度匹配
- 高效长文本处理
